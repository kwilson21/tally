# Phase 0 (Setup) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get Tally from a docs-only repo to a public GitHub repo with a tested Hono Worker skeleton, CI that passes, project rules (`CLAUDE.md`), a roadmap, milestones and issues for Phases 0–4, and a written check of the spec's §13 assumptions.

**Architecture:** One Cloudflare Worker written in TypeScript with Hono. It serves server-rendered JSX pages plus a health endpoint, and static files come from `public/`. Tests run inside the Workers runtime through `@cloudflare/vitest-plugin`. Biome handles lint and format. GitHub Actions runs type-check, lint, and tests on every push and pull request.

**Tech stack:** Node 22, TypeScript, Hono, Wrangler, Vitest + `@cloudflare/vitest-plugin`, Biome, GitHub Actions, `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-09-22-tally-design.md` (all section references below point to it).

**Docs checked on 2026-09-22 (Context7):**
- Hono on Workers: `export default { fetch: app.fetch, scheduled }`, `new Hono<{ Bindings }>()`, and JSX via `"jsx": "react-jsx"` + `"jsxImportSource": "hono/jsx"`.
- Vitest integration: the package is **`@cloudflare/vitest-plugin`** (formerly `@cloudflare/vitest-pool-workers`), configured with `cloudflareTest({ wrangler: { configPath } })` in `vitest.config.ts`. Tests call `exports.default.fetch()` from `cloudflare:workers`, which does not serve static assets. Test tsconfig types: `@cloudflare/vitest-plugin/types`.
- Wrangler: `assets: { directory, binding: "ASSETS" }` in `wrangler.jsonc`. `npx wrangler types` generates `worker-configuration.d.ts`.

**Owner checkpoints (stop and ask):**
- Task 10: creating the public GitHub repo.
- Task 9: any spec change the docs check turns up.

A family budgeting app. It pulls in bank transactions, sorts them into categories with a small AI model, and shows how much is left to spend this month.
